본 개인정보처리방침은 WebNews Tool Ext (이하 “본 확장프로그램”)가 어떤 정보를 수집·저장·이용하는지를 설명합니다.

1. 수집·저장하는 정보

본 확장프로그램은 사용자의 로컬 브라우저 저장소(chrome.storage.local)에 다음 정보를 저장합니다.

모든 데이터는 사용자의 브라우저에만 저장되며, 본 확장프로그램 운영자의 외부 서버로 전송되지 않습니다.

2. 정보의 전송 (Data Transmission)

본 확장프로그램은 사용자가 직접 설정한 Google Apps Script 엔드포인트로만 데이터를 전송합니다.

  • 수신 측: 사용자(또는 사용자가 속한 조직)가 직접 배포한 Google Apps Script Web App
  • 전송 데이터:
    • 사용자가 모니터링 중 선정한 뉴스 기사 정보 (제목, 언론사, URL, 게시일 등)
    • 작업자 LDAP ID
  • 목적: 선정된 기사를 Google Sheets에 기록하기 위함
  • 제3자 전송 없음: 본 확장프로그램 운영자 또는 그 외 제3자에게 데이터를 전송하지 않습니다.

본 확장프로그램은 사용자가 방문한 웹페이지의 내용을 외부로 전송하지 않습니다. 페이지 내 광고 차단 및 키워드 하이라이트는 모두 로컬에서 수행됩니다.

3. 권한 사용 사유

content_scripts (http/https)다음 검색결과에서 클릭한 외부 언론사 기사 페이지에서 광고 차단 CSS 및 정보 하이라이트 적용

4. 데이터 보관 및 삭제

  • 보관 위치: 사용자의 로컬 Chrome 브라우저 (chrome.storage.local)
  • 보관 기간: 사용자가 확장프로그램을 삭제할 때까지
  • 삭제 방법: chrome://extensions에서 본 확장프로그램을 제거하면 모든 로컬 데이터가 함께 삭제됩니다.
